# 果冻照片 · 设计文档

日期：2026-07-13
状态：已通过头脑风暴评审，待写实现计划

## 一句话概述

一个手机网页小玩具：上传一张照片，用涂抹笔刷出想要"果冻化"的区域，然后甩手机让那块区域Q弹抖动，或用手指按住拖拽让它像史莱姆一样拉丝形变、松手弹回。

## 目标与非目标

**目标**
- 手机浏览器打开即用，产出为可分享链接的纯前端静态网页。
- 一支涂抹笔标记一块区域，同一块区域同时支持"甩手机抖动"和"手指拖拽拉丝"两种玩法。
- 抖动幅度等手感参数用户可实时调节。
- 手感真实：Q弹、拉丝、松手回弹，边缘自然过渡。

**非目标（YAGNI）**
- 不做原生 App / 小程序。
- 不做多区域多支笔（确认为一支笔一块区域）。
- 不做保存/导出视频、账号系统、社交分享内容。
- 不做背景填洞（拉丝为原地形变，不把区域整块抠离背景）。

## 技术路线

**路线A：WebGL 网格弹簧模拟**（已选定）

照片作为纹理贴在一张网格 Mesh 上（默认 40×40 网点，按图片大小自适应）。涂抹区域对应的网点被标记为"软"。每个网点带弹簧物理：回位弹簧 + 邻居弹簧 + 阻尼。甩动/拖拽对软网点施力，弹簧解算产生Q弹与拉丝，统一一套物理系统。

**技术栈**
- PixiJS（WebGL 渲染 + Mesh 网格 + 纹理管理，2D 友好）
- 原生 DeviceMotion API（读甩动，含 iOS 授权）
- 原生 Pointer 事件（读手指/鼠标拖拽）
- 纯前端单页，可部署到任意 HTTPS 静态托管（如 GitHub Pages）

被否决的路线：
- 路线B（Canvas 2D 三角拼贴）：手机上实时抖动会卡，Q弹感差。
- 路线C（CSS/SVG 位移滤镜）：无法做局部拉丝弹簧，手感假。

## 页面流程（4步）

1. **上传照片** — 选图，图片铺满画布（自适应缩放居中）。
2. **涂抹标记** — 在图上刷，刷过处显示半透明彩色蒙层；支持擦除、清空重涂。蒙层浓度 = 软度。
3. **开始玩** — 点"开始"，蒙层淡出；iOS 弹出运动数据授权，点允许。
4. **玩** — 甩手机→标记区域果冻抖动；手指按住标记区域拖→拉丝形变、松手弹回；侧边参数面板实时调手感。

## 模块拆分

每个模块单一职责、接口清晰、可独立理解与测试。

- **`ImageLoader`** — 上传照片、读为 PixiJS 纹理、计算铺满画布的显示尺寸与位置。
  - 输入：用户选择的图片文件。输出：纹理 + 显示布局。
- **`MaskPainter`** — 涂抹步骤，管画笔在离屏蒙层上刷/擦并实时高亮。
  - 输出：软硬地图（每像素 0~1 的软度）。
- **`JellyMesh`** — 核心渲染。把纹理贴到网格，持有网点的 rest/pos/vel，每帧渲染变形后的图。
  - 输入：纹理 + 软硬地图。
- **`SpringSolver`** — 纯物理，不碰渲染。每帧按弹簧规则更新所有网点 pos/vel（回位弹簧 + 邻居弹簧 + 阻尼），Verlet 积分。手感来源，独立便于调参与测试。
- **`ShakeInput`** — 监听 DeviceMotion，把加速度转为冲量注入软网点；管 iOS 授权与降级。
- **`DragInput`** — 监听 Pointer，按住把最近软网点绑到手指、拖动、松手释放。
- **`ControlPanel`** — 参数面板 UI，实时调幅度/软硬/回弹/衰减，值直接喂给 SpringSolver。
- **`App`** — 串联各模块，管理 4 步流程的状态切换。

**数据流**：`ImageLoader`→纹理 与 `MaskPainter`→软硬地图 一起进 `JellyMesh`；`ShakeInput` + `DragInput` 对 `SpringSolver` 施力 → 解算出新网点位置 → `JellyMesh` 渲染。

## 物理引擎细节

每个网点持有：`rest`（原位）、`pos`（当前位置）、`vel`（速度）。每帧（~1/60s）对每个软网点计算：

1. **回位弹簧**：力 = `刚度 × (rest − pos)`，把网点拉回原位；刚度越大越硬。
2. **邻居弹簧**：与上下左右邻居间的弹簧，产生"拉丝"和"整片同颤"。
3. **阻尼**：每帧 `vel × 衰减系数(<1)`，让抖动逐渐停下；越接近 1 越"久久很弹"。

**软硬地图应用**：涂得越浓软度越高 → 回位弹簧越弱、位移越大、抖得越夸张；未涂处软度=0，完全固定。边缘从"抖"到"不抖"自然过渡，无生硬切边。

**甩手机**：加速度方向 × "幅度"参数 → 初速度注入所有软网点 → 弹出后靠回位弹簧+阻尼Q弹收回。

**手指拖拽**：按住时最近软网点被钉在手指位置，其余靠邻居弹簧被拉着走（拉丝）；松手解除钉住，全靠弹簧弹回原位。

**性能**：Verlet 积分（快）；网格默认 40×40，按图片尺寸自适应，避免手机卡顿。

## 参数面板

4 个实时生效滑块：
- **抖动幅度** — 甩动注入力的大小（轻颤 ↔ 弹飞）。
- **软硬** — 回位弹簧刚度（软布丁 ↔ 硬果冻）。
- **回弹快慢** — 弹回原位的速度。
- **余韵/衰减** — 抖动持续时长（一下就停 ↔ 晃老半天）。

两个按钮：**重新涂抹**（回标记步骤改区域）、**换照片**。

## 边界情况处理

- **没涂就点开始** → 提示"先涂抹要抖动的地方"，阻止进入。
- **不支持/拒绝运动授权**（电脑或 iOS 拒绝）→ 甩动玩法降级，拖拽玩法照常；顶部提示"当前设备不支持甩动，可用手指拖拽"。
- **图片过大** → 加载时缩到画布合适尺寸，网格密度有上限，防卡。
- **拖太狠拉烂网格** → 邻居弹簧设最大拉伸限制，松手必弹回原位，不永久变形。
- **横竖屏切换** → 重算画布与图片布局。

## 测试策略

- **SpringSolver** 可脱离渲染单测：给定初速度，验证网点在 N 帧后收敛回 rest（衰减正确）、验证邻居弹簧使相邻点跟随。
- **MaskPainter** 单测：刷/擦后软硬地图数值符合预期。
- 交互与渲染层通过手机真机 + 桌面浏览器手动 QA（甩动需真机）。
